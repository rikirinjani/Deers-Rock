# Epic IX M9.3 — Owner Decisions on Oracle Blockers

**Date:** 2026-10-06
**ADR:** ADR-016
**Decided by:** Owner (as stated in conversation)

## Decisions

### 1. Catchment provinces / data coherence
**Decision:** Restrict senders to Sulawesi province set (73) + eastern Indonesia provinces. Relocate Jakarta/Surabaya/Aceh facilities to eastern Indonesia or exclude them as senders. Keep the 35-facility roster but route geography through a `catchmentZone` field.

### 2. Seed-break timing
**Decision:** One declared seed break in wave 1. Re-freeze baseline as `referral-v1`. This breaks existing frozen trajectories — acceptable per ADR-015 precedent (`finance-v2`). Do NOT block on JAMIA submission sequencing; document the break clearly.

### 3. Deers-Rock's tier
**Decision:** Deers-Rock is **RS C** (Tier C). Add 2-3 RS B records as outgoing referral targets. RS A deferred to wave 3 (helicopter tier needs east-Indonesia catchment).

### 4. Domain parameters (ballpark defaults, tune later)
- `REFERRAL_DAILY_SLOT_BUDGET`: **5** letters per 15-tick pass (≈20/day simulated)
- Letter age-out K: **500 ticks** (≈8.3 sim-hours) → moves to `returned`
- Ambulance BLS: base 200k + 2k/km; ALS: base 500k + 5k/km
- Speed: BLS 60 km/h, ALS 80 km/h, helicopter 200 km/h (wave 3)
- Vitals-instability uptriade p-table (base==3): mild complaints 0.05, moderate 0.15, severe 0.25
- Transfer-out criterion: acuity≤2 AND no ICU bed available (10% rng roll fallback)

### 5. JR scope policy
**Decision (revised by the owner 2026-10-31):** Jasa Raharja covers **traffic accidents only**, as it does in practice (UU 33 & 34/1964; a police traffic-accident report backs every claim). Payer and incident use one rule: an encounter is Jasa Raharja-paid, and opens or joins a Jasa Raharja incident, exactly when it is a traffic accident. That means a transport-accident code (V01–V99), or a trauma injury (S00–S99, T00–T14) whose mechanism is traffic. The mechanism is explicit on the patient, or drawn once per patient: traffic with P = 0.45 (Riskesdas: motorcycle crashes 40.6 % of injuries). Burns, poisonings and complications of care (T15–T98) are no longer Jasa Raharja. Implemented in `finance.ts` (`injuryMechanism`, `assignPayer`) and `jr-provenance.ts` (`checkJrTrigger`).
